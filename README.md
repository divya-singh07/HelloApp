# HelloApp

## Overview
HelloApp is a Java-based application that starts with a simple "Hello World" program and gradually evolves into a modular application with features like user input, collections, persistence, and banner display.

## Purpose
The purpose of this project is to learn Java concepts step-by-step using structured use cases.

## Features
- Basic console output
- Command-line input handling
- Standard input processing
- Collection management (add, list, remove)
- Code refactoring into classes
- Data persistence across runs
- Banner-style output

## How to Run
1. Compile the program:
   javac HelloApp.java

2. Run the program:
   java HelloApp
